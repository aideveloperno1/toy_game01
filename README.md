# 복불복 — 내기 게임 모음

친구들과 내기할 때 폰 하나로 당첨자·꽝을 정하는 모바일 웹앱입니다. 설치 없이 링크로 열고, 한 번 열어 두면 오프라인에서도 동작합니다(PWA).

## 게임 10종

| 게임 | 방식 | 인원 |
| --- | --- | --- |
| 사다리타기 | 같이 보기 | 2~12명 |
| 룰렛 | 같이 보기 (탈락식) | 2~20명 |
| 구슬 레이스 | 같이 보기 (물리 시뮬레이션, 맵 3종) | 2~30명 |
| 동물 경주 | 같이 보기 (역전·사진 판정 연출) | 2~12명 |
| 카드 뒤집기 | 돌아가며 | 2~20명 |
| 폭탄 돌리기 | 돌아가며 (폰을 옆 사람에게) | 2~12명 |
| 스크래치 복권 | 돌아가며 | 2~20명 |
| 해적 통 | 돌아가며 | 2~12명 |
| 10초 맞추기 | 실력 | 2~20명 |
| 손가락 터치 뽑기 | 이름 없이 즉석 (홈 화면) | 2~10명 |

모든 게임에서 결과 방식을 고를 수 있습니다.

- **꽝 / 당첨:** K명에게 꽝(벌칙) 또는 당첨(좋은 결과)
- **항목 나누기:** "밥값 1, 커피 2"처럼 항목별로 배정, 나머지는 통과
- **전체 순위:** 1등부터 N등까지

그 밖에 멤버를 모임으로 저장해 다음에 바로 불러오기, 최근 50판 기록과 모임별 벌칙 횟수, 같은 판 다시 보기, 결과 이미지 공유, 게임 랜덤 선택, 소리·진동, 다크·라이트 테마를 지원합니다.

## 공정성

- 게임을 시작하는 순간 Web Crypto로 32바이트 판 번호(seed)를 만들고, 그 seed로 결과를 먼저 정합니다. 게임 화면은 정해진 결과를 보여주는 연출입니다.
- 판 번호의 짧은 표시(예: `#A3F9`)는 게임 중과 결과 화면에 모두 나옵니다.
- 카드 뒤집기·해적 통처럼 직접 고르는 게임은 배치를 시작 전에 정해둡니다. 해적 통의 구멍 수는 남은 인원의 배수라 모두 같은 횟수만큼 꽂습니다.
- 폭탄 돌리기는 꽝이 될 사람을 먼저 정하고 그 사람 차례에 터집니다. 15초 넘게 들고 있으면 자동으로 넘어가고, 그래도 결과는 바뀌지 않습니다.
- 구슬 레이스는 번호만 붙은 구슬로 시뮬레이션한 뒤 "p번째 도착 구슬 = 순위 p번째 사람"으로 이름을 붙입니다. 맵의 유불리가 결과에 영향을 주지 않습니다.
- 같은 멤버로 5분 안에 다시 하면 "재경기 N회차"가 표시됩니다.

`tests/fairness`의 자동 테스트가 게임별로 10만 회씩 시뮬레이션해 각자의 꽝 확률이 K/N ±1% 안인지(카이제곱 검정 포함) 확인합니다. 참여형 게임은 "항상 첫 칸 / 항상 끝 칸 / 무작위" 세 가지 선택 전략으로 각각 확인합니다.

## 실행

Node.js 20.19 이상(LTS 권장)이 필요합니다.

```bash
npm install
npm run dev      # 개발 서버. 같은 Wi-Fi의 폰에서 터미널에 나온 Network 주소로 접속
npm test         # 공정성·사다리·폭탄·해적 통·구슬 시뮬레이션 테스트
npm run build    # dist/ 에 정적 파일 생성
npm run preview  # 빌드 결과 미리보기
```

## 배포 (GitHub Pages)

`main` 브랜치에 푸시하면 `.github/workflows/deploy.yml`이 테스트·빌드 후 GitHub Pages에 올립니다. 처음 한 번은 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔 주세요. 주소는 `https://<계정>.github.io/<저장소>/` 입니다.

## 구조

```
src/
├─ core/          # 게임과 무관한 추첨 엔진 (rng.ts, draw.ts, types.ts)
├─ store/app.ts   # 화면 상태, 참가자, 모임, 기록, 설정 (localStorage 저장)
├─ screens/       # 홈, 참가자, 결과 정하기, 게임 고르기, 진행, 결과, 기록, 설정, 손가락 뽑기
├─ games/
│  ├─ registry.ts # 게임 목록. 새 게임은 폴더 하나 + 여기 한 줄
│  ├─ _kit/       # 차례 넘기기 화면, 연타 방지, 결과 색 등 공통 부품
│  └─ <게임>/     # 게임별 화면 + 순수 로직(logic.ts)
├─ lib/           # 효과음(Web Audio 합성), 진동·화면 꺼짐 방지, 공유 이미지
└─ styles/
tests/fairness/   # 공정성 테스트
```

## 기획서 대비 달라진 점

- 효과음은 음원 파일 대신 Web Audio로 합성합니다. 라이선스 확인이 필요 없고 용량이 0입니다. 그래서 Howler.js를 쓰지 않습니다.
- 애니메이션은 CSS와 requestAnimationFrame으로 처리해 Motion 라이브러리를 쓰지 않습니다.
- 기록은 50판 규모라 IndexedDB 대신 localStorage에 저장합니다.
- 제목용 글꼴은 Pretendard 대신 둥근 손글씨 느낌의 Jua를 쓰고, 본문은 기기 기본 글꼴을 씁니다. 글꼴은 쓰는 글자 조각만 내려받아 저장합니다.
